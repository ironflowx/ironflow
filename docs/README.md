# Docs

The binary and the CLI as they are now. Each PR that changes them updates these files. The engine and its library crates are documented in [foundation's docs](https://github.com/ironflowx/foundation/tree/main/docs).

| File | Read it for |
|---|---|
| [`architecture.md`](architecture.md) | The crates here, the call path in front of the engine, the host and the CLI |
| [`decisions.md`](decisions.md) | The decisions behind them, with their foundation numbers |
| [`invariants.md`](invariants.md) | Serving properties and their proofs, including the server crash test |
| [`behaviors/`](behaviors/README.md) | The executable scenarios and how they run against the binary |
